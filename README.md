# Колода — карточки английских слов

Веб-приложение для изучения английских слов и фраз по карточкам. Работает в браузере на телефоне и компьютере.

Сайт: https://bhpolly.github.io/koloda/

## Возможности
- Добавление слова или фразы на английском или русском: варианты перевода, транскрипция, примеры, аудио.
- Тренировка партиями от 5 до 25 слов: знакомство, выбор перевода в обе стороны, сопоставление пар, сборка из букв, ввод с клавиатуры.
- Интервальные повторения: 1, 3, 7, 16, 35, 80, 180 дней.
- Обучение подборками: «Учить» берёт слова с незакрытым уровнем (новые и пришедшие на повтор), «Тренировать» берёт слова с закрытым уровнем и прогресс не меняет. Оценка слова за тренировку: без ошибок уровень +1 (новое слово сразу получает 2-й уровень, «Уже знаю» даёт 4-й), одна ошибка — уровень не меняется, две и больше — уровень −1. Кнопка «Отметить выученным» ставит прогресс 100%.
- Теги и подборки: у слова может быть несколько тегов, по тегу можно фильтровать список и учить отдельную подборку. Прогресс у слова один на все подборки.
- Слова: поиск, сортировка, постраничный показ (колода из сотен слов), выбор нескольких слов, массовые теги и удаление, управление тегами (переименовать, объединить, удалить), поиск дублей по английскому слову.
- Незаконченная тренировка сохраняется и предлагается продолжить; несколько вкладок синхронизируются; браузер предупреждает, если не может сохранять данные.
- «Изучено» = слово прошло хотя бы первый уровень, «надолго» = уровень 4 и выше.
- Цель дня: сколько новых слов выучить и лимит повторений. Закрытый день продлевает серию, один пропуск в неделю её не рвёт. Повторения идут по важности (просроченные и слабые первыми), сроки слегка разносятся по дням, накопившийся «хвост» можно разложить на ближайшие дни. Проблемные слова (3+ неудачи) выделяются отдельно.
- Задания: выбор, пары, сборка из букв, ввод и пропуск в предложении. Доли форматов зависят от уровня слова: на низких больше узнавания, на высоких больше вспоминания. Знакомство показывается только новым словам.
- Карточки: источник примера и пометка «машинный перевод», фильтр «Неполные», главный пример, подбор примеров под уровень (A2–C1), добавление незнакомого слова нажатием на него в примере.
- Знакомство для новичков: пошаговый тур по интерфейсу (можно пропустить, повторить в настройках).
- Прогресс: путь слов по уровням, подсказки «?», прогноз повторений, активность, серия дней, трудные слова.
- Грамматика: заметки с правилом, примерами и частыми ошибками (❌→✅), теги, поиск, примеры можно озвучить. Хранятся там же, где колода, и входят в резервную копию.
- Аккаунт (email + пароль или Google): колода хранится в облаке и доступна на любом устройстве. Без входа всё работает, слова хранятся в браузере.

## Безопасность и приватность
- **Каждый видит только свои данные.** Доступ ограничен на уровне базы (Row Level Security в PostgreSQL): даже с публичным ключом нельзя прочитать или изменить чужие карточки. Правила лежат в [`supabase/schema.sql`](supabase/schema.sql).
- **Минимум данных.** На сервере только email, карточки, заметки по грамматике, настройки и статистика. Пароль хранит Supabase в виде хеша.
- **Удаление в один клик.** Настройки → Аккаунт → Удалить: аккаунт и все карточки удаляются сразу.
- **Ничего лишнего не загружается.** Шрифты (Montserrat, Oswald, Playfair Display), иллюстрации и библиотека supabase-js лежат в этом репозитории, без CDN. Нет рекламы, счётчиков и аналитики.
- **Строгая Content Security Policy.** Страница может выполнять только свои скрипты и обращаться только к Supabase, MyMemory, Free Dictionary API, Wiktionary и Tatoeba.
- **Данные проверяются.** Всё, что приходит с сервера или из импорта, приводится к ожидаемому формату и экранируется перед показом.
- **Выход с общего компьютера** стирает локальную копию колоды.
- В словари и Tatoeba уходит только само слово, без email и привязки к аккаунту.

## Источники данных
- Переводы: [MyMemory](https://mymemory.translated.net).
- Определения, транскрипция и аудио: [Free Dictionary API](https://dictionaryapi.dev), [Wiktionary](https://en.wiktionary.org).
- Офлайн-транскрипция для любых слов и фраз: словарь [CMUdict](vendor/cmudict-LICENSE.txt) (`vendor/ipa-us.json.gz`, собирается `tools/build_ipa.mjs`).
- Частотный список для подбора примеров: [wordfreq](https://github.com/rspeer/wordfreq) (CC BY-SA 4.0), 3000 самых частых слов встроены в страницу.
- Счётчик запросов к внешним сервисам и проверка их доступности: Настройки → «Проверить».
- Примеры предложений с русским переводом: [Tatoeba](https://tatoeba.org) (CC BY 2.0 FR).
- Аккаунты и база: [Supabase](https://supabase.com), регион EU (Frankfurt).

## Настройка (для владельца)
1. В Supabase: SQL Editor → вставить `supabase/schema.sql` → Run (при обновлении приложения запускать заново: файл безопасен для повторного запуска, он добавит новые таблицы, например для заметок).
2. Вписать Project URL и anon-ключ в `config.js`. Ключ `service_role` в репозиторий не добавлять никогда.
