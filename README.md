# Колода — карточки английских слов

Веб-приложение для изучения английских слов и фраз по карточкам. Работает в браузере на телефоне и компьютере.

Сайт: https://bhpolly.github.io/koloda/

## Возможности
- Добавление слова или фразы на английском или русском: варианты перевода, транскрипция, примеры, аудио.
- Тренировка партиями от 5 до 25 слов: знакомство, выбор перевода в обе стороны, сопоставление пар, сборка из букв, ввод с клавиатуры.
- Интервальные повторения: 1, 3, 7, 16, 35, 80, 180 дней.
- Прогресс: состояние колоды, прогноз повторений, активность, серия дней, трудные слова.
- Аккаунт (email + пароль или Google): колода хранится в облаке и доступна на любом устройстве. Без входа всё работает, слова хранятся в браузере.

## Безопасность и приватность
- **Каждый видит только свои данные.** Доступ ограничен на уровне базы (Row Level Security в PostgreSQL): даже с публичным ключом нельзя прочитать или изменить чужие карточки. Правила лежат в [`supabase/schema.sql`](supabase/schema.sql).
- **Минимум данных.** На сервере только email, карточки, настройки и статистика. Пароль хранит Supabase в виде хеша.
- **Удаление в один клик.** Настройки → Аккаунт → Удалить: аккаунт и все карточки удаляются сразу.
- **Ничего лишнего не загружается.** Шрифты и библиотека supabase-js лежат в этом репозитории, без CDN. Нет рекламы, счётчиков и аналитики.
- **Строгая Content Security Policy.** Страница может выполнять только свои скрипты и обращаться только к Supabase, MyMemory и Free Dictionary API.
- **Данные проверяются.** Всё, что приходит с сервера или из импорта, приводится к ожидаемому формату и экранируется перед показом.
- **Выход с общего компьютера** стирает локальную копию колоды.
- В словари уходит только само слово, без email и привязки к аккаунту.

## Источники данных
- Переводы: [MyMemory](https://mymemory.translated.net).
- Определения, транскрипция, примеры и аудио: [Free Dictionary API](https://dictionaryapi.dev).
- Аккаунты и база: [Supabase](https://supabase.com), регион EU (Frankfurt).

## Настройка (для владельца)
1. В Supabase: SQL Editor → вставить `supabase/schema.sql` → Run.
2. Вписать Project URL и anon-ключ в `config.js`. Ключ `service_role` в репозиторий не добавлять никогда.
