# Колода — карточки английских слов

Веб-приложение для изучения английских слов и фраз по карточкам. Работает в браузере на телефоне и компьютере, без сервера и регистрации.

## Возможности
- Добавление слова или фразы на английском или русском: варианты перевода, транскрипция, примеры, аудио.
- Тренировка партиями от 5 до 25 слов: знакомство, выбор перевода в обе стороны, сопоставление пар, сборка из букв, ввод с клавиатуры.
- Интервальные повторения: 1, 3, 7, 16, 35, 80, 180 дней.
- Прогресс: состояние колоды, прогноз повторений, активность, серия дней, трудные слова.
- Импорт списком, резервная копия в JSON.

## Источники данных
- Переводы: [MyMemory](https://mymemory.translated.net) — бесплатно, около 5 000 символов в день; с email в настройках около 50 000.
- Определения, транскрипция, примеры и аудио: [Free Dictionary API](https://dictionaryapi.dev).
- Если записи носителя нет, слово озвучивает синтез речи браузера.

Колода хранится в `localStorage` браузера. Чтобы перенести её на другое устройство: Настройки → Резервная копия.
